IP Addressing: Every Device Has an Address

An IP address is a unique number given to every device on a network, much like a house address for mail. The older IPv4 format is four numbers between 0 and 255 separated by dots, for example 192.168.1.10, which allows about 4.3 billion addresses. Because the world ran out of these, IPv6 was created, using longer addresses written with colons, such as 2001:0db8:85a3::8a2e:0370:7334.

A router connects your private network to the internet and assigns local addresses to your devices using DHCP. Some addresses, like 192.168.x.x or 10.x.x.x, are reserved for private use and are reused in homes all over the world, while your router shares a single public address with all of them.
